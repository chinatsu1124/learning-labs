01 / mental model

先理解 tmux 到底在管什么

tmux 不是新的 shell，也不是新的终端模拟器。它运行在服务器或本机里，帮你维护一个长期存在的工作区。SSH 断了、终端关了，里面的命令还可以继续跑。

tmux object model
session
一套工作区。例如 api、blog、ops。断开后可以重新 attach 回来。
window
session 里的标签页。通常按任务拆：编辑器、服务日志、数据库、测试。
pane
window 里的分屏。适合同时看命令输出、日志、监控、REPL。

$ npm run dev

02 / first run

从这 6 条命令开始

先把命令跑顺，再记快捷键。日常使用里最重要的是：创建、离开、查看、恢复、结束。

create

新建会话

  • tmux 直接进入默认会话
  • tmux new -s work 创建名为 work 的会话
detach

临时离开

  • Ctrl-b d detach
  • 会话留在后台，任务继续运行
attach

恢复现场

  • tmux ls 查看会话
  • tmux attach -t work 回到 work
clean

结束会话

  • exit 退出当前 pane 的 shell
  • tmux kill-session -t work 删除会话
prefix rule

默认所有 tmux 快捷键都先按 Ctrl-b，松开后再按后续键。例如新建窗口是 Ctrl-b c，不是三个键同时按。

03 / keyboard map

常用快捷键只需要 先记一屏

下面这些键覆盖了 80% 的 tmux 使用场景。先把前缀键 Ctrl-b 练成肌肉记忆，再慢慢加配置。

daily shortcuts
Ctrl-b d离开当前 session，后台继续运行
Ctrl-b c创建新 window
Ctrl-b ,重命名当前 window
Ctrl-b n / p切到下一个 / 上一个 window
Ctrl-b 0..9按编号切换 window
Ctrl-b %左右分屏
Ctrl-b "上下分屏
Ctrl-b o切换到下一个 pane
Ctrl-b x关闭当前 pane
Ctrl-b z当前 pane 最大化 / 还原
Ctrl-b [进入复制模式，用方向键或 vi 键滚动
Ctrl-b ?查看所有快捷键

05 / copy mode

复制模式解决 滚屏和取日志

在 tmux 里，鼠标滚轮可能被终端、shell、程序本身同时影响。稳定做法是进入 tmux 的复制模式，再搜索、选择、复制。

scroll

回看输出

  • Ctrl-b [ 进入复制模式
  • q 退出复制模式
search

搜索日志

  • /error 向下搜 error
  • n 跳到下一个结果
copy

vi 风格复制

  • Space 开始选择
  • Enter 复制选区
06 / config

一个够用的 ~/.tmux.conf

配置不是必须，但下面这份能把常见摩擦点降下来：鼠标、vi 复制模式、更大的历史缓冲、从 1 开始编号、重载配置快捷键。

# ~/.tmux.conf # 使用鼠标选择 pane、调整大小、滚动历史 set -g mouse on # 历史输出保留更多行 set -g history-limit 50000 # window / pane 从 1 开始编号，更贴近键盘数字 set -g base-index 1 setw -g pane-base-index 1 # 复制模式使用 vi 键位 setw -g mode-keys vi # 快速重载配置：Ctrl-b r bind r source-file ~/.tmux.conf \; display-message "tmux.conf reloaded" # 更直觉的分屏键 bind | split-window -h bind - split-window -v
reload

改完配置后，在 tmux 里按 Ctrl-b r。如果这条绑定还没生效，就先运行 tmux source-file ~/.tmux.conf。

07 / troubleshooting

出问题时先查这几项

nested

套娃 tmux

  • 状态栏里已经有 tmux 时，不要再直接 tmux
  • 需要套娃时用 Ctrl-b b 把前缀传给内层
server

找不到会话

  • tmux ls 确认还有没有 session
  • 如果服务器重启过，tmux 里的进程也会消失
color

颜色不对

  • 优先检查终端的 true color 支持
  • SSH、tmux、编辑器的 TERM 设置要一致
exit

关不掉 pane

  • 先让前台程序退出，例如 Ctrl-c
  • 再用 exit 或 Ctrl-b x
