矩阵与线性变换 —— 看见矩阵把整个平面怎么折腾，行列式、秩、Wx+b 一并打通
01 / THE PLAYGROUND

一个 2×2 矩阵，搬动整个平面

读懂矩阵的钥匙只有一句话：矩阵的每一列，是基向量变换后落脚的位置。第 1 列 = e₁(1,0) 去哪了，第 2 列 = e₂(0,1) 去哪了——确定了这两支箭，整个平面上每个点的去向就全部确定（这就是"线性"的含义）。点预设、拖滑杆，看网格和单位方块怎么变👇

playground · 点预设或拖滑杆，实时变换
为什么叫"线性"变换

线性变换保两件事：原点不动、直线还是直线且等距刻度不变（网格变形后依然是平行等距的网格）。代数上即 A(u+v) = Au+Av、A(kv) = kAv——变换"尊重"加法和数乘，这正是上一篇里向量空间仅有的两个操作。

02 / COMPOSITION

矩阵乘法 = 变换接力，顺序有讲究

两个矩阵相乘 AB，意思是"先做 B，再做 A"（离向量近的先执行：A(Bx)）。矩阵乘法的一切怪规则——为什么行乘列、为什么 AB ≠ BA——都是"变换复合"的自然结果。下面用旋转 45°（R）和剪切（S）两个动作做实验，切换执行顺序👇

experiment · 同样两个动作，不同顺序
深度网络 = 一长串复合

一个 N 层网络的前向传播就是 W₃·σ(W₂·σ(W₁x)) 式的接力。注意中间夹着的非线性激活 σ非常关键：没有它，W₃W₂W₁ 可以预先乘成一个矩阵——一百层线性层等价于一层，网络再深也只会画直线边界。深度学习的表达力 = 线性变换 × 非线性弯折的交替。

03 / DETERMINANT & RANK

行列式与秩：变换的"体检报告"

回到第 01 节的操场，其实读数里一直显示着一项 det（行列式）。对 2×2 矩阵，det = ad − bc，它的几何含义干净利落：单位方块变换后的面积倍数（带符号：负数 = 平面被翻了个面）。

cheatsheet · det 一眼读出变换的健康状况
// 行列式 det(A) 的速读表 det = 2 → 面积放大 2 倍 det = 1 → 面积不变（纯旋转/剪切） det = -1 → 面积不变，但平面被镜面翻转 det = 0.1 → 压得很扁，数值上开始危险（病态） det = 0 → 压扁成线/点：列向量线性相关，秩 < 2，不可逆

det = 0 正是主页讲过的线性相关在矩阵身上的表现：两列共线 → e₁ 和 e₂ 落到同一条直线上 → 整个平面被压进这条线 → 秩 1。压缩丢失的维度无法恢复，所以det = 0 ⇔ 不可逆 ⇔ 列线性相关 ⇔ 秩亏，四种说法一件事。在操场里点"压扁（奇异）"预设可以亲眼看到。

逆矩阵：变换的"撤销键"

A⁻¹ 是把 A 的动作精确倒放的矩阵：A⁻¹A = I（恒等）。解方程组 Ax = b 概念上就是 x = A⁻¹b——"是谁被 A 变成了 b？"。但工程上几乎从不显式求逆：数值不稳定且浪费，库函数都用分解法（LU/QR）直接解。

04 / NEURAL NETWORKS

回到 AI：Wx + b 到底在干嘛

现在重新读神经网络的全连接层，每个符号都有了画面：

anatomy · 一层网络的逐符号解读
h = ReLU( Wx + b ) W → 线性变换：旋转/拉伸/压缩输入空间，把"有用的方向"拉开、没用的压扁 b → 平移：线性变换动不了原点，加个偏置补上（仿射变换） ReLU → 非线性弯折：负的归零。没有它，再多层也只是一个矩阵（见 02 节） // 维度对账：输入 768 维 → 输出 3072 维 // W: (3072, 768) x: (768,) b: (3072,) h: (3072,)
batch 也是矩阵乘

一次喂 32 条样本？把它们按列（或行）摞成矩阵 X，WX 一次乘法同时变换 32 个向量——矩阵 × 矩阵 = 一批向量同时过同一个变换。GPU 的并行算力正好吃这碗饭，这就是 batch 训练快的线性代数原因。
