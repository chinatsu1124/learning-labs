EIGEN & SVD

特征值与 SVD —— 找到变换中不变的轴，再用它压缩世界：PCA、低秩近似与 LoRA
01 / EIGENVECTOR HUNT

特征向量：亲手把它找出来

定义一行字：Av = λv——被 A 变换后方向不变（还在原直线上），只被拉伸 λ 倍的向量 v 叫特征向量，λ 叫特征值。光看定义没感觉，自己转一圈找找看：下面固定了矩阵 A = [[2,1],[1,2]]，拖动角度旋转输入向量 v（青色），观察输出 Av（紫色）——大多数方向两支箭岔开，但有两个方向它们会突然对齐👇

detector · 旋转 v，找到两支箭对齐的方向
20°
剧透与体检

这个 A 的特征方向在 45°（λ=3）和 135°（λ=1）。特征值就是矩阵的"体检指标"：它沿哪些轴用多大力气拉伸。对称矩阵（如协方差矩阵）的特征向量还互相垂直——这正是下面 PCA 能成立的原因。

AI 里的特征值

PageRank：整个互联网的链接矩阵的最大特征向量，每个分量就是一个网页的重要性；训练稳定性：权重矩阵特征值长期 >1，信号逐层放大 → 梯度爆炸，<1 → 梯度消失；谱归一化就是按最大奇异值约束矩阵的"拉伸力"。

02 / SVD

SVD：任何矩阵 = 旋转 × 拉伸 × 旋转

特征分解只适用于方阵，而SVD 对任何形状的矩阵都成立：A = U Σ Vᵀ。翻译成几何：再复杂的线性变换，都能拆成三个朴素动作——先转正（Vᵀ） → 沿坐标轴拉伸（Σ） → 再转到位（U）。点击"下一步"，看一个单位圆被三步加工成椭圆👇

simulator · 单位圆的三步加工流水线
单位圆→ Vᵀ 旋转→ Σ 拉伸→ U 旋转
奇异值 = 排好序的重要性

Σ 对角线上的奇异值 σ₁ ≥ σ₂ ≥ … ≥ 0 是椭圆各轴的长度，按"这个方向有多重要"从大到小排好了序。很多真实矩阵的奇异值断崖式衰减——前几个很大，后面几乎为零。这意味着矩阵的"有效信息"集中在前几个方向上，于是有了下面的玩法：扔掉小的。

03 / PCA

PCA：把数据沿"最有戏"的方向压扁

PCA 回答一个问题：高维数据想压到低维，往哪个方向投影丢的信息最少？答案：协方差矩阵的最大特征向量方向（方差最大 = 信息最多）。下面是 200 个相关的二维数据点，逐步看 PCA 怎么把它们降成一维👇

experiment · 200 个数据点的降维三连
从 2 维到 1536 维

真实场景：把 1536 维 embedding 用 PCA 压到 2~3 维做可视化（你见过的那些"语义地图"散点图）、压到几十维给下游模型提速省存储。逻辑与这里完全相同——找方差大的正交方向，按特征值大小保留前 k 个。

04 / LOW-RANK & LORA

低秩近似：LoRA 微调的省钱数学

SVD 给了一个惊人的承诺（Eckart–Young 定理）：只保留前 k 个奇异值得到的秩 k 矩阵，是所有秩 k 矩阵里对原矩阵的最佳近似。把这个思想用在微调上，就是 LoRA：微调不必改动整个 W，训练一个秩 r 很小的增量 ΔW = B·A 就够了——因为"适配新任务所需的改动"本身就近似低秩。

ledger · 一层 4096×4096 注意力权重的微调账本
// 全量微调：直接更新 W W : (4096 × 4096) = 16,777,216 个可训练参数 // LoRA（r = 8）：冻结 W，训练 ΔW = B·A B : (4096 × 8) = 32,768 A : (8 × 4096) = 32,768 合计 = 65,536 个可训练参数 ≈ 全量的 0.4% // 前向：h = W·x + B·(A·x) —— 原模型一字未动，外挂一条低秩旁路
同一思想的其他化身

推荐系统：把"用户×物品"打分大矩阵分解成两个瘦矩阵（用户向量 × 物品向量），缺失的格子用点积补全；模型压缩：把大权重矩阵 SVD 截断成两个小矩阵相乘，推理省内存；图像压缩：保留前 k 个奇异值就是经典的低秩图像压缩。一套数学，处处开花。
