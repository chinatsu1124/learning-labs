01 / ADD & SCALE

只有两种合法操作：相加、伸缩

向量空间里允许的基本动作只有两个：向量加法（对应分量相加，几何上是"首尾相接"）和数乘（每个分量乘同一个数，几何上是伸缩/反向）。一切"线性"的东西——线性组合、线性变换、线性相关——都是这两个动作搭出来的。拖动滑杆，看 v₁ + v₂ 的平行四边形怎么变👇

为什么只关心这两个动作

因为它们是在任何维度都成立的操作。1536 维的 embedding 没法画，但 0.5·v猫 + 0.5·v狗 照样算得出来——著名的 word2vec 算式 king − man + woman ≈ queen，用的就只有加法和数乘。

02 / DOT PRODUCT

点积：把"有多同向"变成一个数

点积的代数定义平平无奇：a·b = a₁b₁ + a₂b₂ + …，对应分量相乘再加起来。但它的几何身份才是重点：a·b = |a||b|cosθ——夹角越小值越大，垂直为零，反向为负。它还给出投影：b 在 a 方向上的"影子"长度。拖动角度，盯住数值的正负变化👇

AI 里点积出现的地方

注意力机制：每个 query 向量和所有 key 向量做点积，得到"该关注谁"的分数表——Transformer 的核心公式 softmax(QKᵀ/√d)V 里，QKᵀ 就是一大批点积同时算；向量检索：把问题 embedding 和库里所有文档 embedding 做点积/余弦，取分数最高的几条，就是 RAG 的"检索"。

03 / NORMS

范数：向量"有多大"的几种量法

范数（norm）就是向量长度的推广。最常用的两种量法走的是不同哲学：

contrast · 同一个向量 v = [3, -4] 的两种长度

L1 范数 · 曼哈顿距离

‖v‖₁ = |3| + |−4| = 7
  • 量法：所有分量绝对值相加，像在棋盘街道上走路
  • 性格：对每个分量"一视同仁"
  • AI 用途：L1 正则化逼参数变成精确的 0 → 稀疏模型、特征选择

L2 范数 · 欧氏距离

‖v‖₂ = √(3² + 4²) = 5
  • 量法：平方和开根号，就是直线距离（勾股定理）
  • 性格：重罚大分量（平方放大）
  • AI 用途：L2 正则化（weight decay）把参数整体压小但不归零；梯度裁剪按 L2 范数缩放
归一化：把长度抹平

向量除以自己的 L2 范数，得到单位向量（长度 1，方向不变）。embedding 入库前常做这一步——归一化之后，点积就等于余弦相似度，比较时只剩"方向"这一个变量，长度差异不再干扰排序。

04 / COSINE SIMILARITY

余弦相似度：embedding 世界的通用尺子

把 a·b = |a||b|cosθ 倒过来，就得到 cosθ = a·b / (|a||b|)：值域 [−1, 1]，1 = 同向，0 = 无关，−1 = 反向。它只看方向、不看长度，所以"一句长文"和"一句短文"也能公平比较。下面是 6 个词的玩具 embedding（4 维，维度含义：动物 / 宠物 / 财务 / 运动），点击任意两个词，看相似度怎么算出来👇

从玩具到真实

真实 embedding 的维度是几百到几千，而且每一维没有人类可读的含义——它们是模型自己学出来的坐标系。但数学完全一样：把这里的 4 维换成 1536 维，循环多跑几圈而已。这就是为什么先在低维建立直觉如此划算。

code · 一次向量检索的全部代码
# RAG 检索的核心就这几行 def cosine(a, b): return dot(a, b) / (norm(a) * norm(b)) q = embed("怎么退订会员？") # 问题 → 向量 scores = [cosine(q, d) for d in docs] # 和库里每条文档比方向 top3 = argsort(scores)[-3:] # 取最像的 3 条，塞给 LLM
